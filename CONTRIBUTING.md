# Contributing to WaveAMP for VS Code

**English** | [Русский](#участие-в-waveamp-для-vs-code)

Thanks for your interest in WaveAMP!

WaveAMP is developed by its author; pull requests from outside contributors
aren't accepted. You can help with bug reports and ideas.

## Reporting bugs and suggesting features

Use [Issues](https://github.com/darkdkl/waveamp-vscode/issues) and pick the bug
report or feature request template. For bugs, include the WaveAMP version (the
Extensions view shows it next to the name), your VS Code version (Help →
About), your OS and the steps to reproduce. Logs help a lot: open View →
Output, pick **WaveAMP** in the list, reproduce the problem and copy what it
shows.

Please report security vulnerabilities privately — see [SECURITY.md](SECURITY.md).

# Участие в WaveAMP для VS Code

[English](#contributing-to-waveamp-for-vs-code) | **Русский**

Спасибо за интерес к WaveAMP!

WaveAMP разрабатывает его автор; pull request'ы от сторонних участников не
принимаются. Помочь можно сообщениями об ошибках и идеями.

## Ошибки и предложения

Пишите в [Issues](https://github.com/darkdkl/waveamp-vscode/issues), выбрав
шаблон «ошибка» или «предложение». Для ошибок укажите версию WaveAMP (она
видна рядом с названием в панели Extensions), версию VS Code (Help → About),
систему и шаги для воспроизведения. Очень помогают логи: откройте View →
Output, выберите в списке **WaveAMP**, повторите проблему и скопируйте то, что
там появилось.

Об уязвимостях сообщайте закрыто — см. [SECURITY.md](SECURITY.md).
